# Golang песочница

Здесь я разбираю паттерны и другие темы на Go.
У каждого примера есть реализация и демонстрация запуска.

## Примеры

| Паттерн | Варианты | Что делает |
| --- | --- | --- |
| [Worker Pool](concurrency/workerpool) | basic, results, cancellable | Считает сумму квадратов несколькими воркерами |
| [Pipeline](concurrency/pipeline) | basic, cancellable | Передаёт числа по этапам: квадраты → фильтр чётных |


## Запуск

Нужен Go 1.26 или новее. Команды выполняются из корня репозитория:

```sh
go run ./concurrency/workerpool
go run ./concurrency/pipeline
```

Каждая команда запускает все варианты своего примера.
Входные числа случайные, от 10 до 99, поэтому вывод меняется между запусками.
Сейчас варианты с контекстом запускаются без досрочной отмены.

## Структура

- `concurrency/` — примеры работы с горутинами и каналами.
- `main.go` внутри примера — подготовка данных и запуск демонстраций.
- `internal/number/` — общий генератор чисел для демонстраций.

## Проверки

```sh
go vet ./...
go test -race ./...
go run -race ./concurrency/workerpool
go run -race ./concurrency/pipeline
```

Запуски с `-race` проверяют гонки только в выполненных сценариях.
